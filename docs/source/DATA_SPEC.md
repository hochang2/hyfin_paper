# 데이터 명세서 (Data Spec) — 단일종목 레버리지 연구

> 2026-10-23 작성. 다운로드 전 설계 문서. 분석에서 필요한 것만 나중에 골라 쓴다는 전제로 **분봉은 넓게 받아 둔다**.
> 우선순위: **P0** = 키움 분봉, 약 1년 롤링 보관으로 보여 지금 받지 않으면 사라짐 / **P1** = 키움 일별, 저렴하고 DataGuide에 없을 수 있는 항목 / **P2** = DataGuide·외부 소스, 나중에 받음

## 1. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 종목 키 | KRX 단축코드 6자리 (`005930`, `0193T0`). 키움 접미사 `_NX`, `_AL`은 별도 컬럼 `venue`(KRX/NXT/ALL)로 분리. DataGuide 코드는 앞에 `A`를 붙이고, ETN은 `Q`일 가능성이 있어 확인 필요 |
| 시간 | KST. 분봉 시각은 **바의 시작 시각** (1519 = 15:19:00~15:19:59, ✅ 검증함) |
| 정규장 필터 | 정제 파일의 `session` 열로 구분: `regular` 09:00~15:19, `close` 15:30 바(종가 단일가, 연장된 날은 15:32), `pre` NXT 08:00~08:59, `after` 15:35 이후. 수능일(2025-11-13)은 10:00~16:19 + 16:30, 새해 첫날(2026-01-02)은 10:00 개장. 미국은 동부시간 `pre` 04:00~ / `regular` 09:30~15:59 / `post` 16:00~ / `overnight` 20:00~(24시 이상 표기) |
| 가격 | `upd_stkpc_tp=1` (수정주가). 수정주가는 소급 변경될 수 있으므로 다운로드 날짜(`asof`)를 기록. 기초자산 2종은 원주가(`0`)도 함께 받음 |
| 숫자 | 키움 원본은 문자열이고 +/− 부호는 전일 대비 상승/하락 표시 → 가격은 `abs()` 처리, 원본은 그대로 보존 |
| 거래량 | 가격·RV는 **KRX 코드**, 거래량은 **_AL 코드**(= KRX+NXT, 바 단위로 일치 ✅). NXT 단독 거래량 = _AL − KRX |
| 저장 | 원본 `data/raw/minute/<작업명>/p00000.json` (응답 그대로) → `downloader/clean.py` → `data/clean/minute/<작업명>.parquet` + `_catalog.csv`(작업별 요약). 검증은 `downloader/validate.py` |
| 재개 | 다운로드는 종목·페이지 단위로 체크포인트를 남겨, 중단돼도 이어받을 수 있게 함 |
| 호출 한도 | API ID당 약 5건/초. 분봉(ka10080)은 하나의 ID라 순차 처리 (약 4건/초 기준으로 시간 추정) |

## 4. 다운로드 후 검증 항목

| 검증 | 기준 |
|---|---|
| 분봉 → 일봉 일치 | 09:00~15:30 분봉의 시가·고가·저가·종가 = 일봉 (✅ 005930 하루로 확인함) |
| 거래량 일치 | 분봉 거래량 합 ≈ 일봉 거래량. KRX는 약 0.4% 부족할 수 있음 (시간외 종가매매로 추정) |
| ALL = KRX + NXT | 바 단위로 일치 (✅ 2026-10-24 전 구간 검증: 005930·000660·005935 100% 일치. NXT 미거래 종목 ALL=KRX: 252670만 6개 봉 차이, 나머지 완전 일치) |
| 시장 전체 공백 | KOSPI 지수 정규장에서 29분씩 빈 날 9일(2026-03-04, 03-09, 06-08, 06-23, 06-26, 07-07, 07-13, 07-28, 07-29) → `data/clean/minute/_market_gaps.csv`. 서킷브레이커(20분 정지+10분 단일가) 형태로 보이나 KRX 공지로 확인 필요. RV 계산 시 공백 앞뒤를 한 수익률로 처리 |
| 봉 누락 | 거래가 없는 분은 봉이 아예 없음(거래량 0 봉 없음). 저유동 종목·상품(예: 253150, 409810, 0193K0, 0194N0, 520100)은 하루 봉 수가 적음 → 저유동 종목은 5분 이상 간격 RV 사용 |
| 날짜 누락 | 거래일 캘린더와 대조. 거래정지일과 특수일(수능일 등 개장 지연) 표시 |
| 일별 바 개수 | 정규장 381개(1분)에서 크게 벗어나는 날 플래그 |
| 롤링 보관 | **월 단위 롤링 확정** (2026-11-04 `check_rolling.py`: 국내 20251103~, 미국 20260501~). 추가 기간은 `download.py --period`로 `data/raw/minute_ext/<기간>/`에 받고 `clean.py`가 합침. 2026-10 추가 완료 (2026-11-04, 데이터 끝 20261030). 기간 사이 수정주가 소급 조정은 겹친 봉의 비율로 앞 기간 가격을 맞춤 → `_catalog.csv`의 `adj_factor` (2026-10: 207940 0.9923, 0194N0, 0194R0, 423920) |
