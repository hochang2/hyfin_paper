## 1. 공통 규칙 (F1~F17)

분봉(M1~M7)은 형식이 달라 6절에 따로 적었다 (코드에 `A` 없음, 날짜 `YYYYMMDD` 문자열, parquet만).

- **세트마다 이름이 같은 `.csv`와 `.parquet`.** 내용은 같다.
  - CSV는 UTF-8 BOM이라 엑셀에서 바로 열린다. parquet은 날짜·숫자형이 보존되고 빠르다 (`pd.read_parquet`).
- **long 형식**: 일간 = 한 행이 `date × code`, 결산 = `code × fiscal_year`. F16만 `date × 변수`.
- `date`: 한국 영업일 (`YYYY-MM-DD`). F16의 FRED 변수만 미국 영업일.
- `code`: DataGuide 코드
  - 주식·ETF `A` + 6자리 (`A005930`, `A0193T0`), ETN `Q` + 6자리 (`Q520100`)
  - 국내 지수 `I.xxx`, 해외 종목 `FJ.티커`
  - 앞 글자를 떼면 키움 코드 (F2·F8의 `kiwoom_code`)
- **F17만 `종목코드`가 6자리 문자열** (`A` 없음, 엑셀에서 열면 앞자리 0이 사라짐 → `dtype={"종목코드": str}`).
- 값이 없으면 빈칸(NaN). **0으로 채우지 않았다.** 값이 전부 빈 행(상장 전 등)은 뺐다.
- **금액은 따로 적지 않으면 원.** 예외: `F10.aum_mil`(백만원), `F16` 일부(억원), `F17.상장시가총액`(백만원), `F14` 해외 종목 종가(달러).

### 6.6 정제 규칙과 사용 예

1. 원본 JSON 페이지를 합치고, 같은 시각 중복은 앞의 것을 남긴 뒤 시간순 정렬.
2. 가격 부호 제거, 지수 ÷100, 거래량 정수 변환.
3. 월별로 추가로 받은 구간을 합칠 때, 겹치는 봉의 종가 비율 중앙값으로 그 사이 생긴 수정주가 조정을 추정해 **앞 구간 가격에 곱함** → 전 기간이 최신 수정주가 기준. 지수·`_raw`는 조정하지 않음.
   - 조정된 파일: 0194N0(0.999404), 0194R0(0.999101), 207940(0.9923), 423920(0.998301), 각 KRX·ALL
4. **거래가 없는 분은 봉이 없음.** 거래가 드문 종목·ETF는 정규장 봉이 380개보다 적다.

```python
import numpy as np, pandas as pd
df = pd.read_parquet("data/interim/minute/005930_KRX_1m.parquet")
reg = df[df.session == "regular"].set_index("ts")
# 일별 5분 실현변동성 (거래 없는 분은 직전 종가로 채움)
c5 = reg.close.groupby(reg.date).resample("5min").last().ffill()
rv = (np.log(c5).groupby(level=0).diff() ** 2).groupby(level=0).sum()
```
