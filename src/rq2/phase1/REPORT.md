# RQ2 Phase 1 최종 보고서 — 여러 반사실 상황으로 본 규제 효과 (2026-11)

- **질문.** 2026-07 단일종목 레버리지 상품 규제(07-16 발표, 07-31 시행)가 기초자산 005930(삼성전자)·000660(SK하이닉스)의 실현변동성을 "상품은 있으나 규제는 없는" 반사실보다 낮췄는가.
- **자료.** 2025-10-01 ~ 2026-10-30 (학습 190일, transition 10일, 시행 후 61일). 결과변수는 5분봉 log RV(rv5)다.
- **접근.**
  - 하나의 반사실 모형에 결론을 걸지 않는다.
  - 서로 다른 가정으로 만든 **여러 반사실 상황**(주 결과, 보조 결과, 음성통제, 민감도)을 나란히 놓는다.
  - 각 상황이 무엇을 배제하고 무엇을 남기는지 함께 읽어 추론한다.
- **이 문서의 역할.** 아래 다섯 하위 연구를 하나로 묶은 결론이다. 새 분석은 없고, 숫자의 근거는 각 보고서에 있다.

| 폴더 | 질문 | 보고서 |
|---|---|---|
| `main_study` | 사전 지정 주 분석 (BSTS, 같은 기업 차분, placebo, 강건성) | [main_study/results/REPORT.md](main_study/results/REPORT.md) |
| `ml_extension` | ML·FM 을 넣으면 반사실·검출력이 좋아지나 | [ml_extension/results/REPORT.md](ml_extension/results/REPORT.md) |
| `ml_followup` | 무엇이 정확도·추론 신뢰도를 실제로 개선하나 | [ml_followup/results/REPORT.md](ml_followup/results/REPORT.md) |
| `ensemble` | 재학습 없는 선택적 앙상블과 표본 밖 검증 | [ensemble/results/REPORT.md](ensemble/results/REPORT.md) |

- 효과는 모두 61일 평균 (실제 − 반사실)이고, 단위는 % = exp(log 차이) − 1 이다.
- "p" 는 모형 구간이 아니라 placebo 로 보정한 경험적 p 다.

## 1. 결론

**시행 후 61거래일 동안 두 종목의 실현변동성이 반사실보다 낮았다는 통계적 증거는 없다.** 이 판단은 §2 의 어느 반사실 상황에서도 바뀌지 않는다.

그러나 상황들을 함께 보면 다음 두 가지도 분명하다.
- **"효과가 없었다"는 결론은 아니다.** 검정력이 낮아 −10~−20% 규모의 감소는 어느 상황에서도 검출할 수 없다. −20% 효과를 잡을 확률은 BSTS 11%, 같은 기업 차분 31% 다.
- **반사실을 어떻게 만드느냐에 따라 부호가 갈린다.** 시장 냉각을 반사실에 얼마나 반영하는지가 핵심 축이다.
  - 덜 반영하는 상황(kosdaq_lrv 중심, 미국 변수, 긴 표본): 0 또는 증가
  - 더 반영하는 상황(don_mean 중심, 음성통제 맞춤 보정): −10~−20% 감소

## 2. 반사실 상황별 증거

각 행은 "규제가 없었다면 변동성이 어땠을까"를 서로 다른 가정으로 만든 하나의 반사실이다.

**역할 구분**
- **주:** 사전 지정 판정의 근거
- **보조:** 다른 가정으로 같은 질문에 답함
- **점검:** 반사실 자체가 맞는지 확인
- **민감도:** 가정이 틀렸을 때를 모사

### 2.2 상황들을 함께 읽기

**(1) 모든 상황에 공통인 것.**
- 61일 평균에서 유의한 감소를 보인 상황은 하나도 없다.
- 유의한 감소를 만들려면 경험적으로 드문 가정 위반이 필요하다(sensitivity §3, §5).
  - bias ≥ 0.57~0.68 (차분 ≥ 0.36): 경험 분포의 상위 6% 이내
  - 가장 강한 관측 통제의 2.6~3.9배인 숨은 교란
- → **"유의한 감소는 없다"는 상황 의존적이지 않다.**

**(2) 음성통제가 말해 주는 것 (S3).**
- 상품이 없는 005935 가 S1 에서 +21% 로 나온다. 즉 S1 반사실은 사후기간에 대형주 변동성을 체계적으로 **과소예측**한다.
- 이 편향은 S4~S8 모든 모형에서 같은 방향이다(005935 +19~+35%).
- 그래서 처치 종목의 값은 절대값보다 **음성통제와의 차이**로 읽는 것이 더 믿을 만하다.
  - S1 기준: 005930 − 005935 ≈ −16%p, 000660 − 005935 ≈ −26%p
  - 이 차이는 모든 모형에서 음수다(ml_extension §7).
- 이것을 반사실 수준에서 직접 보정한 것이 S9(−11~−13%)다.

**(3) 상황들이 갈리는 축: 시장 냉각을 반사실에 얼마나 넣느냐.**
- 사후기간에 국내 시장 변동성은 상장기간보다 크게 내려갔다(donor 평균 −1.24 sd).
- 이 냉각을 어떤 변수로 대표하느냐에 따라 반사실이 위아래로 움직인다.

| 냉각을 덜 반영 (반사실 높음 → 효과 0 또는 +) | 냉각을 더 반영 (반사실 낮음 → 효과 −) |
|---|---|
| S5 미국 변수만 (+40~92%) | S10 kosdaq_lrv 제외 (don_mean 중심, −17~−18%) |
| S10 don_mean 제외 (kosdaq_lrv 중심, +10~23%) | S9 음성통제 맞춤 bias 보정 (−11~−13%) |
| S6 긴 표본 GK (+15~43%) | S12 시장 민감도 외삽 (−7~−13%) |

- 주 결과 S1(≈ 0)은 두 통제가 상쇄된 중간점이다.
- **어느 쪽이 맞는지 이 자료로 가릴 수 없다는 것이 Phase 1 의 핵심 불확실성이다.**
- 음성통제(S3)는 "더 반영" 쪽을 약하게 지지한다. 그러나 S12 의 직접 통제(−0.6%)는 그렇지 않다.

**(4) 같은 기업 대조(S2)의 위치.**
- 시장 냉각 문제를 기업 내부 비교로 피해 가는 유일한 설계다.
- 005930 의 비교환적 사전 추세(donor 94분위)도 우선주(94분위)와 상쇄된다.
- 결과는 +2.4% 이고, 약 28% 초과 감소를 배제한다. MDE 는 −38% 로 가장 작다.
- 남는 위험은 두 가지다.
  - 우선주 동조: S11 의 차분판에서는 동조 91% 면 −20% 가 0 으로 보인다.
  - 시장 민감도 차이: S12.
- 000660 에는 이 설계가 없다.

**(5) 모형을 바꾸는 것은 상황을 바꾸지 못한다 (S4, S8).**
- 모형 간 오차 상관이 0.89~0.97 이다. ML·FM·앙상블은 정확도를 최대 5~10% 올렸지만 MDE·FPR 은 그대로였다.
- 결론을 움직인 것은 **모형 형태가 아니라 반사실에 들어가는 정보(통제, 대조군, bias 가정)** 다.
- 추론 신뢰도를 크게 바꾼 것은 n_eff·strict 시간 null 같은 추론 방식이었다(ml_followup Exp5: FPR 13~44% → 1~10%).

**(6) 시점(S13).**
- 시행 직후 상승은 07-28 서킷브레이커·8월 초 급락과 겹친다. 음성통제와 시장 전체도 함께 상승했다.
- 후반(31~61일)의 000660·차분 −11% 는 시차 효과와 평균 회귀를 구별할 수 없다.
- 사전 등록 창이 아니므로 판정에 쓰지 않는다.

## 5. 논문 반영

**본문**
1. **반사실 상황 표의 축약판(§2.1 에서 S1·S2·S3·S5·S9·S10 의 6행).** 주 결과와 보조 결과를 한 표에서 보여 준다.
2. **결론 문장:** §4 왼쪽 열.
3. **"상황들이 갈리는 축" 한 문단(§2.2 (3)).** 부호가 정해지지 않는 이유를 설명한다.
4. **검정력 문단.** 핵심 문장: "검출력의 병목은 반사실 모형이 아니라 처치 종목 2개, 사건 1회라는 설계다."
5. **같은 기업 대조의 장점과 한계** 한 문단.

**부록**
- S4·S6·S7 전체 표와 placebo FPR (main_study)
- S8: ML 벤치마크·튜닝·앙상블 (ml_extension, ensemble)
- 추론 방식별 FPR (ml_followup Exp5)
- S9~S13 전체 민감도 (sensitivity). 창·사건일은 "사전 등록 아님"을 명시한다.

## 6. 한계

1. **검정력.** 처치 2종목, 사건 1회, 사후 61일이다. 어떤 상황에서도 −20% 를 안정적으로 검출할 수 없다.
2. **시장 냉각을 대표하는 통제의 선택.** don_mean 과 kosdaq_lrv 가 반대 방향으로 작용한다. 어느 쪽이 "규제 없는 세계"의 냉각을 바르게 대표하는지 자료로 정할 수 없다.
3. **000660 대조 부재.** 같은 기업 대조가 없어 S1 계열에만 기댄다.
4. **우선주 가정.** 005935 가 규제 영향을 받지 않았다는 가정은 검정할 수 없다.
5. **측정 차이.** 긴 표본(GK, 일봉)과 주 분석(rv5, 5분봉)이 다르다. rv5 만으로는 61일 창 시간 null 을 만들 수 없다(n_eff < 1).
6. **동시 사건.** 서킷브레이커·급락기·실적발표·옵션만기를 통제하지 못했다.
7. **통제 오염의 크기.** 직접 측정할 자료(donor 종목의 레버리지 수급)가 없다.
