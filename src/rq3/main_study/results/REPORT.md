# RQ3 보고서: ETF 리밸런싱 정보가 삼성전자·SK하이닉스의 다음 날 실현변동성 예측을 개선하는가

작성: 연구자 B (2026-11-18). 실행 코드는 `src/rq3/main_study/`, 설정과 사전 지정은 `src/rq3/config.yaml`, 결과 표·그림은 `src/rq3/main_study/results/`, 실험 로그는 `results/experiment_log.{csv,md}` 에 있다.
재현: `.venv/Scripts/python -m src.rq3.main_study.run_all` (단계: data → primary → judgment → robustness → exploratory). 데이터 로더·캐시·실험 로그는 `src/rq2/core/` 를 수정 없이 쓴다.
예측 대상은 **ln RV** 이다. "표본외 개선 +10%" 는 비교 기준 모형 대비 표본외 MSE 가 10% 줄었다는 뜻이다 (R²oos = 1 − MSE_big / MSE_small).

## 요약 (먼저 읽을 것)

- **결론: 이론적 리밸런싱 압력은 HAR-RV 와 당일 수익률 충격을 넘어서는 표본외 예측력을 보이지 않았다.** 사전 지정 판정 규칙을 적용한 결과 두 종목 모두 '추가 예측력의 증거 없음'이다.
  - 주 검정(C vs B, Clark-West, Holm, 표본외 76개): 005930 표본외 개선 −0.7% (Holm p 0.66), 000660 −7.3% (Holm p 0.66). X 를 넣으면 오차가 오히려 늘었다.
- **다음 날 변동성을 예측하는 정보는 당일 수익률 충격에 있다.** 수익률 크기 R 을 HAR 에 넣으면 두 종목 모두 표본외 MSE 가 약 14% 줄었다 (CW p < 0.001). 하락 방향과 반도체 업종 공통 충격(다른 종목 |r|)도 추가 정보를 준다.
- 리밸런싱 압력 X 의 계수는 이론 방향(양수)이지만, 상장 후 자료가 적은 초기에 과대추정되어(SK 0.41 → 0.19) 표본외 예측을 해쳤다. 구간 내 블록 위약도 통과하지 못했다 (rank p 0.11 / 0.23).
- **탐색적 신호(사후, 결론 아님):** ETF 를 통한 **개인 순매수**가 강한 예측 정보를 보였다 (SK +22.4%, 삼성 +6.4%, 하락 수익률 통제 후에도 +9.8% / +3.9%). 이 결과와 4단계의 '분모 시가총액' 사양은 결과를 보고 세운 가설이므로, 11월 이후 새 자료로 평가할 **2차 가설 S1·S2** 로 등록만 했다.
- **두번째 연구 (사후 탐색, §12, 결론 불변):** 개인 순매수 신호는 SK 에서 날짜 집중도(기여 상위 5일 제외 후 +14%)와 블록 위약(rank p 0.028)은 견디지만, **현물 개인·외국인 순매수와 ATM 내재변동성을 통제하면 +22% → +5%** (하락 수익률까지 통제하면 +1.5%, p 0.074) 로 줄고, 삼성은 모두에 취약하다. ETF 고유 정보보다 개인 매매 전반의 대리일 가능성이 크다. 마감 30분 RV 를 예측 대상으로 해도 리밸런싱 압력 X 는 일관된 개선이 없다.
- **한계:** 표본외 예측이 종목당 76개, 상장 후 106일 하나의 기간뿐이다. 그 기간 안에 규제 발표·시행이 있다.

## 1. 연구 목적과 가설

**질문.** 2026-05-27 상장한 단일종목 레버리지·인버스 상품(종목별 9개)의 이론적 리밸런싱 압력이, 기존 HAR-RV 와 일반적인 주가 충격 정보를 고려한 뒤에도 기초자산의 다음 날 실현변동성 예측을 개선하는가.

**성격.** 예측력 비교다. 인과 효과를 주장하지 않는다.

**가설 H1.** 모형 C 의 표본외 MSE 가 모형 B 보다 작다 (한쪽).

**경로.** 레버리지 ETF 는 장 마감에 기초자산 수익률 방향으로 L(L−1)·AUM·r 만큼 기계적으로 매매한다. 2X 는 L(L−1)=2, −2X 는 6 으로 모두 양수라 매매가 언제나 움직임을 키우는 방향이다.

**사전 지정.** 모형, 변수, 예측 방식, 주 검정, 판정 규칙, 해석 문구, 확증 평가 해석표를 표본외 예측을 처음 돌리기 전에 `config.yaml` 에 적고 별도 커밋(`rq3 사전 지정`, c01bdfa)으로 남겼다. 사전 지정 전 확인한 것은 상품 목록·자료 기간·결측뿐이다. 그때 알고 있던 RQ1·RQ2 결과는 known_before 와 §9 에 적었다. A 의 RQ4 결과는 일부러 읽지 않았다.

## 3. 모형

| 모형 | 설명변수 (상수항 포함 OLS) | 역할 |
|---|---|---|
| A | HAR (ln RV_t, ln 5일 평균, ln 22일 평균) + 상장 더미 D | 기준 |
| B | A + R_t = ln(1 + 100·\|r_t\|) | 수익률 충격 통제 |
| **C** | **B + X_t = ln(1 + 100·\|r_t\|·S_t)**, S_t = ΣL(L−1)·AUM_{t−1} / 거래대금_t | **주 비교 C vs B** |

- **상장 더미를 모든 모형에 넣은 이유:** X 는 상장 전 0, 상장 후 양수라 그 자체가 상장 더미 역할을 일부 한다. RQ1 에서 상장 전후로 변동성 수준이 이미 달랐으므로(05-06 구조변화), 더미 없이는 "ETF 정보"와 "상장 후 변동성 수준"이 섞인다.
- **R 을 통제한 이유:** X = ln(1+100|r|·S) 이므로 X 의 예측력 대부분이 |r| 에서 나올 수 있다. C vs B 는 "같은 크기의 수익률 충격이라도 ETF 규모가 클 때 다음 날 변동성이 더 큰가"를 검정한다. 상장 후 corr(R, X) = 0.93 / 0.94, VIF 9~11 로 실제로 매우 높았다.
- **예측 방식:** 확장 창. 원점 t 마다 2025-11-06 ~ t−1 행으로 다시 추정하고 ln RV_{t+1} 을 예측한다 (원점 t 의 행은 y 가 t+1 에 실현되므로 학습에 넣지 않음). 첫 원점은 상장 후 30번째 거래일 07-08 이고 예측은 07-09 ~ 10-30, 종목당 76개다.
- **검정:** 포함 관계 모형이라 Diebold-Mariano 대신 Clark-West(2007) MSPE-adjusted 한쪽 검정, Newey-West lag 3, 2종목 Holm. QLIKE 는 Clark-West 와 짝이 맞지 않아 보조(DM, 포함 관계에서 보수적)로만 썼다.
- **검증:** 모의자료로 미래 정보 차단, 진짜 예측변수 검출(10회 중 8회 이상), 귀무 하 기각률, 블록 섞기, HAC 를 확인했다. 실제 자료로 상품 구성, 상장 전 0, 전일 AUM 사용, 미래 AUM 변경 무영향을 확인했다 (`tests/`, 18개 통과).

| 005930 vs B | +9.7% (0.20) | +9.3% (0.21) | −1.0% (0.53) | −9.2% (0.78) | −21.7% (0.94) |
| 000660 vs B | +15.2% (0.049) | +15.3% (0.046) | +14.3% (0.035) | +24.6% (0.025) | +13.5% (0.18) |

- SK 는 모든 모형이 B 보다 낫지만, 같은 변수를 넣은 선형 모형(C + 4개 +12.3%, B + IND +22.4%)과 크기가 비슷하다. 개선은 ML 기법이 아니라 IND 변수에서 온 것으로 보인다. 삼성에서 트리 모형은 과적합으로 B 보다 나빴다. 작은 표본에서 ML 이득이 없었다는 RQ2 ML 확장 결과와 맞는다.

**8.4 해석.** 사후에 본 검정이 약 24개다. 가장 강한 SK IND(p 0.00006)는 이 수의 Bonferroni 보정을 감안해도 남지만, 표본외 76개·기간 하나·사후 탐색이라는 한계는 그대로다. 결과가 가리키는 것은 "**ETF 의 기계적 리밸런싱이 아니라 ETF 를 통한 개인 투자자 매매가 변동성 예측 정보를 담을 수 있다**"는 새 가설이며, 증거로 쓰지 않는다.

- **사전에 알고 있던 것 (known_before):** RQ1 결과(상장 후 변동성 상승이 음성통제에서도 같은 크기, 005930·005935 구조변화 05-06), RQ2 결과(5~7월 시장 전체 변동성 급등, 000660 구조변화 05-22, 작은 표본에서 ML 이득 없음). 이 때문에 상장 더미를 주 모형에 넣었다.

## 10. 한계

4. **다음 날 예측만 주 분석이다.** 리밸런싱이 일어나는 마감 30분 RV 를 대상으로 한 분석은 두번째 연구(§12.4, 사후 탐색)에서 했고, X 는 거기서도 일관된 개선이 없었다.
5. **R 과 X 의 공선성(VIF 9~11)** 때문에 X 고유 정보가 작다. 이것은 설계의 한계라기보다 질문의 본질이다.

### 12.5 정리

1. 리밸런싱 압력 X: 마감창을 예측 대상으로 바꿔도 일관된 개선이 없다. 주 결론과 같다.
2. 개인 순매수 IND: SK 에서는 날짜 집중도와 위약을 견디지만, **현물 개인·외국인 매매와 내재변동성을 통제하면 대부분 사라진다** (+22% → +2~5%). 삼성은 날짜 몇 개와 경쟁 변수에 모두 취약하다. 따라서 IND 는 "ETF 고유 정보"라기보다 **개인 투자자 매매 전반의 정보**를 대리했을 가능성이 크다.
3. 확증 평가 S2 는 등록한 그대로 둔다 (B + IND vs B). 새 자료로 평가할 때 이 절의 경쟁 변수 통제 사양을 함께 보고한다.
4. 참고 (A 의 RQ4): F9 순매수는 투자자 유형 합이 0 에 가까워 개인 순매수 ≈ LP·금융투자 순매도다. 규제 후 단일종목 상품 거래가 94% 줄어 확증 기간의 IND 변동은 작을 수 있다 (검정력 저하).
