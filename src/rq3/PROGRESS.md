## 결정 사항
1. 표본: 2025-10-01~2026-10-30 전체(261일). 상장 전 ETF 변수 = 0. 상장 더미를 A·B·C 모두에 넣는다.
2. 주 비교: C(B + 리밸런싱 압력 X) vs B(HAR + D + 수익률 충격 R). 판정은 Holm Clark-West p < 0.05 하나.
3. 부호·위약(규제 구간 안에서 5일 블록 섞기)은 판정 조건이 아니라 해석 근거.
4. 확증 평가: 11월 이후 자료 40거래일 이상이면 같은 모형으로. 해석은 대칭 4칸 표.
5. ETN 포함: aum_won 이 비어 있어 18개 모두 aum_calc(상장증권수 × NAV/지표가치) 사용.
6. A 의 RQ4 결과는 사전 지정 커밋 후에 읽는다.

## 단계 메모

- 설계 행렬: HAR 월 시차 때문에 2025-11-06 부터 240행 (상장 전 134, 후 106). 첫 예측 원점 07-08, 예측 76개.
- 상장 후 corr(R, X) = 0.93 (005930), 0.94 (000660). 예상대로 매우 높다 → 계수 경로·VIF 보고가 중요.
- S(규모 비율)는 상장 후 한 달 동안 올라가 0.8~1.8 사이. 규제 시행 후에도 크게 줄지 않았다.

### 3단계 (2026-11-18)
- 해석 근거 (주 검정 '증거 없음' → 사전 지정 문구 `reading.none` 적용):
  - 전체 표본 X 계수: 005930 +0.10 (NW t 0.98), 000660 +0.19 (t 2.29). 방향은 이론과 같음.
  - VIF(상장 후): X 9.2 / 10.9, R 9.4 / 11.2. 전체 표본 VIF 는 1.7~1.9 (상장 전 X=0 때문).
  - 계수 경로: SK X 계수가 첫 원점 0.41 → 마지막 0.19 로 계속 줄었다. 초기 과대추정 → 표본외 손실의 원인으로 보임. 삼성은 −0.12 에서 시작해 9월 이후 +0.1.
  - 위약(구간 내 5일 블록, 1000번): 실제 CW t 의 rank p 005930 0.107, 000660 0.232.
- 보조:
  - A vs B (R 추가): R²oos +14.2% / +14.0%, CW p 0.0002 / <0.0001, QLIKE DM p 0.008 / 0.013.
  - 음성통제 005935 (삼성 X): R²oos +2.3%, CW p 0.071.
  - 교차: 삼성 X → SK RV +2.6% (p 0.041), SK X → 삼성 RV +2.9% (p 0.021).
    → 교차 X 에는 다른 종목의 |r| 이 들어 있고 B 는 그것을 통제하지 않는다. 반도체 업종 충격 정보로 보는 게 자연스럽다. ETF 경로 근거가 아님 (자기 종목 X 는 개선 없음).
  - 구간별 평균 손실 차이: 상장~발표 전 원점은 6개뿐이라 구간 비교는 기술 통계로만.

### 4단계 (2026-11-18)
- `oos()` 에 target·horizon 추가 (5일 평균 대상은 원점 t 에서 index ≤ t−5 행만 학습). design 에 y_next5, R_u 추가.
- 강건성 10개 사양 × 2종목 = 20개 중 CW p<0.05 는 3개 (우연 기대치 약 1개):
  - 005930 rv_pk +3.9% (p 0.048), 000660 5일 평균 대상 +2.1% (p 0.021), **000660 분모 시가총액 +13.3% (p 0.028)**.
  - 나머지 17개는 개선 없음이거나 음수. 106일만 쓰면 둘 다 −5%, 이동 창도 음수. 일관된 패턴 없음.
- 분모 시가총액: S = ΣL(L−1)AUM / 시가총액 (ETF 보유 비중). 거래대금 분모는 변동성이 큰 날 거래대금도 커져 S 가 작아지는 내생성이 있다 → 시가총액 분모가 개념상 더 깨끗할 수 있음. 단 결과를 보고 나온 생각이므로 사후 가설 (삼성은 +1.1%, p 0.27).
- 탐색(사전 지정 밖) 교차: 다른 종목 |r| 를 넣으면 3개 모두 개선 (p 0.012~0.041), 그 위에 X 를 넣으면 개선 없음 (p 0.27~0.77)
  → 3단계 교차·음성통제의 개선은 반도체 업종 수익률 충격 정보였고 ETF 경로가 아님이 확인됨.
