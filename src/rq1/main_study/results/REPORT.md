# RQ1 보고서: 단일종목 레버리지 상품 상장이 삼성전자·SK하이닉스의 실현변동성을 높였는가

작성: 연구자 B (2026-11-17). 실행 코드는 `src/rq1/main_study/`, 설정과 사전 지정은 `src/rq1/config.yaml`, 결과 표·그림은 `src/rq1/main_study/results/`, 실험 로그는 `results/experiment_log.{csv,md}` 에 있다.
재현: `py -m src.rq1.main_study.run_all` (단계: data → primary → judgment → robustness → exploratory). 반사실 모형·데이터 로더·실험 로그는 `src/rq2/core/` 를 수정 없이 가져다 쓴다.
효과는 모두 **log 실현변동성 차이**다. +0.10 은 약 10% 높다는 뜻이다 (정확히는 exp(β)−1).

## 요약 (먼저 읽을 것)

- **결론: 상품 상장(2026-05-27) 이후 두 종목의 변동성이 상품 때문에 높아졌다는 증거는 없다.** 사전 지정 판정 규칙을 적용한 결과 두 종목 모두 '상장 효과의 증거 없음'이다.
  - 주 검정(패널 DiD, donor 175종목 순열 p, Holm): 005930 β=+0.57 (Holm p 0.11), 000660 β=+0.32 (Holm p 0.23).
- **상장 뒤 변동성이 오른 것 자체는 사실이다.** 점추정은 모든 사양에서 양(+)이다. 그러나 **상품이 없는 비교 종목도 같은 크기로 올랐다.**
  - 삼성전자우(같은 기업, 상품 없음) β=+0.64 (p 0.034) > 삼성전자 +0.57.
  - 반도체 관련 7종목 평균(상품 없음) β=+0.35 (p 0.005) ≈ SK하이닉스 +0.32.
  - 같은 기업 차분(삼성전자 − 삼성전자우)은 −0.07 (rv5) / +0.06 (일별 GK 긴 표본 보정 p 0.67) 로 0 근처다.
- 따라서 상장 기간의 상승은 **반도체 업종과 삼성 기업 전체에 공통된 움직임**으로 보는 것이 자연스럽다. 탐색 분석에서 삼성전자와 삼성전자우의 변동성 수준 변화 시점이 **같은 날(2026-05-06), 상장 3주 전**으로 잡힌 것도 이와 맞는다.
- **검정력은 낮다.** 처치 구간이 35거래일뿐이라 donor 설계의 최소 검출효과(MDE, 80% 검정력)는 0.78 log(약 +118%)다. 같은 기업 차분은 0.47 log(약 +60%). 따라서 "효과가 없다"가 아니라 "**큰 효과의 증거는 없고, 작은 효과는 판단할 수 없다**"로 읽어야 한다.

## 1. 연구 목적과 가설

**질문.** 2026-05-27 상장한 단일종목 레버리지·인버스 ETF 16종·ETN 2종이 기초자산 005930(삼성전자)과 000660(SK하이닉스)의 일별 실현변동성을, 상품이 없는 비교 종목 대비 상대적으로 높였는가.

**가설 H1.** 상장 후(05-27~07-15) 두 종목의 log RV 가 대조 종목 대비 상대적으로 높아졌다 (DiD 효과 > 0). 경로: 레버리지 상품 운용사의 일일 리밸런싱 수요와 레버리지 수요에 따른 주문흐름. 검정은 RQ2 와 맞춰 양측 5% 로 했다.

**처치 구간.** 상장일부터 규제 발표 전날(07-15)까지 35거래일. 07-16 이후는 규제 효과(RQ2) 구간이라 쓰지 않았다.

**RQ2 와의 관계.** RQ2 의 반사실은 "상품은 있고 규제만 없는 세계"다. RQ1 은 그 앞 단계인 "상품이 생긴 효과"를 본다. 두 질문은 겹치지 않는다.

**사전 지정.** 주 검정, 기간, 대조군, 판정 규칙, 두 설계가 엇갈릴 때의 해석 규칙을 분석 코드보다 먼저 `config.yaml` 에 적고 별도 커밋(`rq1 사전 지정`)으로 남겼다. 이 설계는 RQ2 분석 이후 확정했으며, 그때 RQ2 에서 이미 알려진 사항은 `config.yaml` known_before 와 §9 에 밝혔다. RQ1 결과 구간에 대한 효과 추정은 사전 지정 전에 없었다.

## 6. 진단

### 6.1 평행추세 (조건 c)

- **원인**: 삼성전자 − donor 평균이 상장 전 기간 내내 올라간다 (2025-10 약 −0.9 → 2026-03 약 0, 그림 `rq1_data_overview.png`).
- **영향**: 이 추세가 처치 구간까지 이어졌다면 DiD β 는 상장 효과를 과대 추정한다.
- **조치**: 사전 지정대로 결합 검정(p 0.55)으로 판정했고 기각되지 않았다. 다만 상장 전 계수 8개가 모두 양(+)이고 검정력이 낮아 "평행추세가 확인됐다"고 쓰지 않는다.
- **보완 근거**: 같은 기업 차분(삼성전자 − 삼성전자우)은 상장 전 추세가 평평하고(RQ2: +0.005/월, p 0.69), 이 설계의 효과도 0 근처다.

### 6.2 모형 p 와 순열 p 의 차이

HAC 모형 p 는 005930 0.000002, 000660 0.025 로 "매우 유의"하다. 순열 p 는 0.057, 0.233 이다. 모형 p 로 판정했다면 결론이 뒤집혔을 것이다. RQ2 의 교훈(모형 위양성률 0.17~0.78)과 같다.

### 12.4 정리

1. **1차 주 결론은 그대로다.** 어떤 결과변수에서도 "음성통제는 그대로이고 처리 종목만 유의하게 오른" 경우가 없다.
2. **가장 눈여겨볼 결과는 마감창 − 장중이다.** 음성통제가 0 근처이고 처리 종목만 양(+)이라 리밸런싱 경로와 맞는 모양이지만, 유의하지 않다. 이 결과변수는 사후에 골랐으므로 증거가 아니라 다음 검증 대상이다. 상장 효과를 다시 검정하려면 새 사건(다른 종목 단일종목 상품 상장 등)에 이 결과변수를 사전 지정해서 써야 한다.
3. 마감 모멘텀 기울기에는 변화가 없다.
